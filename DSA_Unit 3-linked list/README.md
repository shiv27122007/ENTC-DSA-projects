# DSA Unit 3 - Linked List

## Project Overview
This project demonstrates the implementation of Linked List data structures using C++. It is developed as part of the Data Structures and Algorithms (DSA) coursework.

## Objectives
- Understand the concept and working of linked lists.
- Implement linked list operations using C++.
- Learn dynamic memory allocation and pointer manipulation.
- Practice insertion, deletion, traversal, and searching operations.

## Features
- Create and manage linked list nodes.
- Insert nodes into the list.
- Delete nodes from the list.
- Display linked list elements.
- Search for an element in the list.

## Technologies Used
- Programming Language: C++
- Concepts: Data Structures, Pointers, Dynamic Memory Allocation
